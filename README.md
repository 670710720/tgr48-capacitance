# TGR-48 Capacitance Meter (ESP32)

วัดค่าตัวเก็บประจุด้วย ESP32 โดยใช้ **วิธีที่ 3: ชาร์จตามเวลาที่กำหนด แล้วอ่านแรงดันด้วย ADC** และให้โค้ดเลือกเวลาชาร์จเอง (auto-range)

## วงจร

```
 ESP32
 GPIO25 ──────[ R1 1 MΩ ]──────●──────── GPIO34 (ADC1)
                               │
                              ═╪═  Cx
                               │
 GND ──────────────────────────●
```

- ปุ่มกดวัด: ปุ่ม BOOT บนบอร์ด (GPIO0)
- LED: LED บนบอร์ด (GPIO2)

## การใช้งาน

1. เปิด `tgr48-capacitance.ino` ใน Arduino IDE เลือกบอร์ด **ESP32 Dev Module**
2. อัปโหลด แล้วเปิด Serial Monitor ที่ **9600 baud**
3. เสียบตัวเก็บประจุ รอประมาณ 30 วินาทีโดยไม่จับวงจร แล้วกดปุ่ม BOOT ทิ้ง 1 ครั้ง
4. กด BOOT 1 ครั้งต่อการวัด 1 ครั้ง

ผลลัพธ์:

```
TGR-48
Capacitance = 147279.1 pF
```

## หลักการ

1. **ขั้นหยาบ:** ชาร์จแล้วจับเวลาจนแรงดันถึง 50% เพื่อประมาณ τ = R1 × Cx
2. **ขั้นละเอียด:** ตั้งเวลาชาร์จ t_ch = 0.693τ ให้แรงดันอยู่ประมาณ 50% แล้วคำนวณ

   Cx = −t_ch ÷ ( R1 × ln(1 − Vc/Vcc) )

3. คายประจุ 7τ ก่อนวัดแต่ละรอบ และเฉลี่ย 3–32 รอบ (ตัวเล็กวัดหลายรอบ ตัวใหญ่วัดน้อยรอบ)
4. แก้ค่าด้วยการคาลิเบรต: `(C − C_STRAY_PF) × GAIN`

## ค่าคาลิเบรต (บอร์ดของเรา)

| ค่า | ค่าที่ใช้ | วิธีได้มา |
|---|---|---|
| `R1` | 1.043 MΩ | Fluke 117 วัดตัวต้านทานแบบถอดออกจากวงจร |
| `VCC_MV` | 3268 mV | Fluke 117 วัดขา 3V3 |
| `C_STRAY_PF` | 6.8 pF | วัดตอนไม่ใส่ Cx เฉลี่ย 10 ครั้ง |
| `GAIN` | 0.9765 | เทียบกับตัว 104Z ที่ Fluke 117 วัดได้ 146 nF |

ถ้าเปลี่ยนบอร์ด ตัวต้านทาน หรือการต่อสาย ต้องคาลิเบรตใหม่

## ผลทดสอบ AC

ตัว 104Z (ค่าอ้างอิง 146 nF จาก Fluke 117) วัด 5 ครั้ง:

| ครั้งที่ | 1 | 2 | 3 | 4 | 5 | เฉลี่ย |
|---|---|---|---|---|---|---|
| pF | 146,872.8 | 147,368.9 | 148,819.5 | 147,647.2 | 145,687.1 | 147,279.1 |

- เสถียร: (max − min) ÷ เฉลี่ย = **2.1%** (เกณฑ์ ≤ 5%)
- ตรง: (เฉลี่ย − 146,000) ÷ 146,000 = **+0.9%** (เกณฑ์ ≤ ±10%)

เกณฑ์ 5% และ ±10% เป็นค่าที่ทีมเสนอ และ Fluke 117 เองคลาดได้ประมาณ ±5 nF ที่ค่านี้

## ข้อจำกัด

| ช่วง | สถานะ |
|---|---|
| ต่ำกว่า ~20 pF | วัดไม่ได้ (ADC ของ ESP32 อ่านไม่ทัน และ stray C ใหญ่พอ ๆ กับตัวที่วัด) |
| 50 pF – 100 nF | ยังไม่ได้ทดสอบ |
| ~146 nF | ผ่าน |
| 1–4.8 µF | ยังไม่ได้ทดสอบ (วัดครั้งละหลายวินาที) |
| มากกว่า ~4.8 µF | out of range |

- Fluke 117 วัด C ได้ละเอียดสุด 1 nF จึงใช้อ้างอิงค่าที่ต่ำกว่าประมาณ 100 nF ไม่ได้
- ถ้าต้องการช่วงกว้างกว่านี้ ให้เพิ่มตัวต้านทาน 10 MΩ (GPIO26) และ 10 kΩ (GPIO27) เป็นช่วงวัดเพิ่ม

## ข้อควรระวัง

- ถอด USB ก่อนเปลี่ยนตัวเก็บประจุทุกครั้ง
- ตัวขนาดใหญ่ (µF ขึ้นไป) ให้แตะขาทั้งสองเข้าหากันก่อนเสียบ เพื่อคายไฟที่ค้างอยู่
- ตัวอิเล็กโทรไลต์ต้องใส่ขั้วให้ถูก: ขา + ไปจุด Vc และขา − ไป GND
- ห้ามต่อ GPIO34 เข้า 5 V
